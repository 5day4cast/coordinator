# Coordinator v2.17.1

Weather discovery now loads eligible stations and their forecasts in one Oracle
request. This removes the repeated forecast queries for each group of 100 stations.
The default view refreshes in the background, including when the UTC date changes,
so the first operator visit can use results that are already available.

The page retains its server-rendered cards, map, filters, and native refresh link.
Missing wind and rain values remain unknown. A failed forecast query cannot publish
a partial ranking. Competition creation still rechecks station eligibility.

Deploy Oracle v2.7.0 or later before this Coordinator release. The new discovery
endpoint is required; if it is unavailable, the page reports the failed refresh.
This change requires no database migration or Synth deployment.
