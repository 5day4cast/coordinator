# Coordinator v2.4.0

This release refunds the Arkade escrows of competitions that never filled, registers each entry with Keymeld before the player pays, and creates synth's competitions as unlisted oracle events.

**Compatible components**

| Component | Version |
| --- | --- |
| Keymeld gateway | `v0.5.0` or later |
| Keymeld SDK, core and enclave crates | `v0.6.0` |
| Coordinator verifier enclave and LNURL relay | `v2.4.0` |
| ark-swapd | `v2.4.0` |
| synth | `v2.4.0` |
| NOAA Oracle API | `v2.3.0` or later (for `unlisted` events) |
| dlctix | crates.io `0.1.0` |

**Changes**

- A competition that never filled now refunds its players' escrows. Keymeld registers only the players who are present (`register_partial_roster`, Keymeld v0.6.0) and signs each refund with that player's own key. Refunds wait while any ticket's invoice can still be paid, because Keymeld's roster can't change once registered. (#85)
- The entry form sends the entry's Keymeld registration before it shows the ticket invoice, so a ticket paid for but never entered can still be refunded. A registration is tied to its ticket reservation, deleted when the reservation is released, and cleared when the competition ends; only paid tickets reach Keymeld. No new screens. (#85)
- The operator API and the oracle client take an optional `unlisted` flag for events, and synth creates its competitions unlisted, so they stay out of the oracle's public event lists. (#85)
- synth identifies the payee node from the configured `trail.payee.pubkey`, so payouts are confirmed on the payee's side with a macaroon that can read invoices. (#85)

**Required upgrade steps**

1. Back up the coordinator database. Migration `20261001000000_ticket_keymeld_registrations` adds the `ticket_keymeld_registrations` table.
2. Rebuild and deploy the Keymeld enclaves with the `v2.4.0` verifier enclave before the coordinator. The verifier enclave is built from Keymeld v0.6.0's enclave crate; an older enclave fails a partial-roster refund on its first request.
3. Deploy ark-swapd and synth from this release together with the coordinator.

**Limits**

- A ticket paid after Keymeld has registered a competition's roster can't be refunded automatically; it is logged for an operator.
- One paid player's broken registration pauses refund signing for that competition until it is fixed.
- The coordinator's own competition lists still show unlisted competitions; the flag affects the oracle only.
- Arkade funding and refunds are tested on Mutinynet only. Escrow VTXOs expire 7 days after creation.
