# Coordinator and Synth v2.18.3

This release rebuilds the coordinator verifier enclave against Keymeld 0.8.4.
The SDK, core library, enclave library, relay, and development environment use the same release revision.

Idle enclave session families expire after 48 hours. Finished signing sessions expire after 10 minutes.
Authorized activity refreshes the parent session. Active operations hold the session lock while cleanup checks it.
Sealed escrow state can restore an expired in-memory session. Wire framing, sealing keys, and persistent state formats remain compatible.

Deploy the matching verifier artifact with the Keymeld 0.8.4 gateway. Updating only the gateway does not update verifier enclave code.
Retain persistent escrow state, the witness ledger and its identity, and KMS configuration.

The checkpoint writer still defaults off. After deploying 2.18.2 and then 2.18.3, both rollout slots support format-2 checkpoints.
Operators can then enable `COORDINATOR_PROTOCOL_PARTS=1`. See [the checkpoint runbook](../protocol-checkpoints.md).

This release includes all coordinator and synth fixes documented in [2.18.2](v2.18.2.md).
