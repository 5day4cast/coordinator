# Coordinator and Synth v2.23.1

## Players

A payment whose entry wasn't finished within the hour no longer counts as your entry in a queued competition: it frees its place, Pay starts a new entry, and the entry form and entries page say "Your earlier entry wasn't finished in time; its fee is being refunded".
In a single competition the unfinished payment still holds its seat, so the entry form shows the same line without Pay, and a ticket request for that player is refused with the same sentence instead of "You've already entered this competition".
An entry whose hour runs out while it is being written is refused.
The fee of an unfinished payment is refunded exactly once through the existing refund path.

## Deploying

Deploy Coordinator. This release requires no database migration or configuration change, and no changes to Synth, ark-swapd, or the Keymeld gateway and verifier.
