# Coordinator v2.14.10

This release lands the security review of refunds and web recovery, moves ark-swapd's chain data to the operator's own electrs, corrects the help page's video and finishes the phone tap targets.

**Coordinator**

- Refund invoices are resolved and authorized inside the Keymeld verifier (#191). The verifier resolves the player's Lightning Address and signs a domain-separated digest of the exact invoice and escrow policy. The coordinator stores that receipt in `refund_invoice_authorizations`; the verifier refuses refund signing without it. Public LNURL metadata does not authorize the payment destination. Existing invoices and sealed refund preparations lack this authorization and fail closed. Only eligible, unsubmitted refunds can obtain a replacement through the stale-invoice remint path. Submitted or paid refunds require reconciliation before any replacement; successful recovery has no fixed deadline.
- Password reset work is bounded: active Argon2 work is capped and excess requests are refused before queueing; anonymous reset issuance uses stateless owner-bound challenges with uniform responses (#191).
- NIP-98 proof consumption is persisted in the users database and expiry is rechecked under the write lock (#191).
- The Arkade escrow subscription keeps its backoff across immediate stream failures, and panics were removed from the authentication, TLS, signing, startup and invoice paths (#191).
- The help page's "how it works" video, in both the phone and desktop cuts, still showed a 5% service fee from the fixtures it was recorded from. Both cuts and their posters are recorded again at the 3% fee the entry form charges, with the same length, resolution and encoding (#190).
- On touch screens every small control is now a full 44 px tap target with nothing covering it (#192). The entry form's "?" tips were 44 px boxes whose rounded corners cut the tappable shape to a circle; they are square on touch screens with the ring drawn inside. The map's station pins get an invisible 46 px square around each pin, scaled with the map so it stays the same size on screen. The fee total, the leaderboard "?" and the Copy buttons grow their invisible tap areas to 46 px. Desktop pointers keep every control at its current size.

**ark-swapd**

- Chain lookups go to the operator's electrs over the Electrum protocol instead of a public Esplora API (#191). `esplora_url` is replaced by the required `electrum_url` (`tcp://` or `ssl://`). Esplora, its BDK wallet dependency and the vendored compatibility patch are removed; the key provider, boarding addresses, boarding and renewal, swap payments and refund claims are unchanged.

**Required upgrade steps**

Before rollout, inventory pending refunds using the [refund authorization upgrade procedure](../ops/stuck-escrow-check.md#refund-invoice-authorization-upgrade).
Reconcile submitted or paid refunds against persisted swap, Arkade, and Lightning state before replacing anything.
Do not fabricate authorizations or delete signing history to force retries.
Back up `refund_invoice_authorizations` with the competitions database.

Pin the published `v2.14.10` coordinator, verifier, and ark-swapd artifacts using their verified checksums before deployment.
For deployments using [nixos_setup #14](https://github.com/tee8z/nixos_setup/pull/14), replace the ark-swapd `2.14.9` pin before applying that configuration.
That binary rejects the required `electrum_url` setting.

1. Deploy the verifier enclave from `v2.14.10` to Keymeld before the coordinator: refunds minted by the new coordinator need the enclave's refund-invoice action.
2. ark-swapd: replace `esplora_url` with `electrum_url`, and update the binary and the generated configuration together. Stop the old rollout slot before changing shared configuration. Keep `wallet.key` and `swaps.sqlite`.
3. Deploy the coordinator. It runs the migrations `users/20261001000000_nip98_consumption` and `competitions/20261009000000_refund_invoice_authorizations` on start.
4. synth is unchanged since v2.14.9.

**Compatibility**

Both migrations add tables, but `v2.14.9` rejects applied migration versions absent from its compiled migration set.
Preserve databases, authorization receipts, and signing history; do not drop migration records to force a downgrade.
The older coordinator restores the web vulnerabilities and cannot issue authenticated refund invoices.
The updated verifier rejects legacy refund requests without authorization; reverting the verifier would restore the refund destination vulnerability.
If an emergency rollback is necessary, pause affected workflows and reconcile payment and signing state first.
Rolling ark-swapd back also requires restoring `esplora_url` with the old binary and stopping the other rollout slot before changing shared configuration.

Arkade funding validation remains deferred while the service is paused.
Source review and GitHub CI do not establish a successful funded lifecycle.
