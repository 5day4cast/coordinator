# Coordinator and Synth v2.22.0

## Players

Picks in single competitions can be edited until the start, as in queued competitions. The coordinator now sends a single competition's entries to the oracle at the start instead of when its seats fill, so the oracle event lists them from the start. Contracts are still built and signed as soon as the seats fill.

A player who paid a ticket but whose entry did not go through, for example after a page reload, can finish entering while entries are open. The entry form says "Paid — make your picks to finish entering", and Enter submits the picks under the paid ticket's entry id and key, with no new ticket or payment. The entries page lists these tickets with a link to make picks.

## Synth

A resumed run that had not saved its entry key resumes its oldest unpaid ticket, and a refusal for a different entry key is retried once under the same key.

## API

- `GET /api/v1/competitions/{id}/tickets/paid` lists the caller's paid tickets that have no entry, while entries are open.
- `POST /entries` for a paid ticket may leave out the Keymeld registration; the registration stored before payment is used, and it must match the entry's key.

## Deploying

Deploy Coordinator and Synth. This release requires no database migration or configuration change, and no changes to ark-swapd or the Keymeld gateway and verifier.
