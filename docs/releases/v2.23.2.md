# Coordinator and Synth v2.23.2

## Payouts

Winners of contracts whose outcome transaction carries an anchor output are paid over Lightning again. The payout check expected the outcome transaction to have exactly one output, so for every contract built with the default contract options since v2.20.0 the payout stayed pending with "chain state unavailable". The check now finds the contract output and ignores the anchor (#271).

## Deploying

Deploy Coordinator. This release requires no database migration or configuration change, and no changes to Synth, ark-swapd, or the Keymeld gateway and verifier.
