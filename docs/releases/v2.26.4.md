# Coordinator and Synth v2.26.4

## Queued competition signing

Pools use the locktime recorded in the terms players accepted. A coordinator configuration change between entry and kickoff no longer changes that delay.

New pools save the accepted delay in their event. Older pools read it from their parent queue when creating their first contract. Stored contracts remain unchanged.

## Synthetic admission

Synth recognizes both full-capacity responses from the coordinator. When every seat is paid, an extra actor stands down and the run continues following the funded pool. Server errors and unrelated admission failures still fail the run.

## Upgrade

Upgrade the coordinator and Synth. No database migration or configuration change is required. Restarted Synth runs retain their saved entry and payment records.

Already cancelled pools continue through refunds. This release does not reopen cancelled competitions or rewrite signed contracts.
