# Coordinator v2.14.9

This release stops the request storms against the services the coordinator, ark-swapd and synth depend on. The rule from now on: every external payment data source is followed by subscription first, with slow polling as the fallback.

**Synth**

- The money trail asked the Arkade server's indexer for every tracked outpoint of every followed run every 20 seconds, for eight hours per run: one request per outpoint. It now asks once per pass for all outpoints together, in pages, only for outpoints that can still change, and a run whose competition has not moved is looked at every five minutes; the 20-second cadence lasts two minutes after a state change.

**ark-swapd**

- Each hold invoice was looked up on the Lightning node every second. Each is now followed with `SubscribeSingleInvoice`; the lookup is a fallback every 30 seconds while the stream is up and every 5 seconds while it is not.

**Coordinator**

- The invoice and payout watchers swept every pending item on the Lightning node every 5 seconds although both events are subscribed to. While a subscription is up the sweep runs every 60 seconds (`invoice_watch_interval_subscribed`, `payout_watch_interval_subscribed`); it drops back to 5 seconds while the subscription is down. Gauges `coordinator_ln_invoice_subscription_up` and `coordinator_ln_payment_subscription_up`.
- The chain watcher subscribes to Electrum headers and runs its full pass every 120 seconds (`refresh_blocks_secs_subscribed`) or when a header arrives, instead of every 15 seconds.
- Pending escrows are followed through one subscription on the Arkade indexer (`SubscribeForScripts` / `GetSubscription`): a script is added when a swap is created and removed when the swap is verified paid or ends, and an event for a script verifies that swap at once. If the stream drops the coordinator resubscribes with backoff. The backup is one batched `GetVtxos` for all pending escrows every 30 seconds instead of one listing per swap every two seconds. Gauge `coordinator_escrow_subscription_up`, counter `coordinator_escrow_events_total`.
- A paid escrow swap is looked up only once ark-swapd names what it paid, and a lookup that finds nothing backs off per swap from 2 seconds to a minute.

**Required upgrade steps**

1. Deploy ark-swapd, the coordinator and synth from `v2.14.9`. No migrations. New optional coordinator settings named above.

**Compatibility**

Rolling back to v2.14.8 is safe.
