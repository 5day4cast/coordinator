# Coordinator and Synth v2.24.1

## Recovery

- The recovery tools carry the Mutinynet coordinator's recovery key and its relay `wss://5day4cast.com/relay`, so `coordinator-recover inspect` needs only the player's nsec.
- Operators can republish recovery records to a newly added relay: `coordinator admin recovery republish --relay <url>`, the Services page, or `POST /api/v1/admin/recovery/republish`. `coordinator admin recovery status` shows what each relay still lacks.
- Recovery records whose money is settled are deleted from the relays with NIP-09 deletions after `[recovery].settled_retention_days` (default 7). Set `delete_settled = false` to keep them.
- Relay retries back off at most 5 minutes, and a relay that comes back gets the waiting events at once.

## Deploying

Deploy Coordinator. Relays must accept kind 5 (NIP-09 deletions) from the recovery key before the first settled records reach their retention age. Migration `recovery_retention` adds columns and indexes to `recovery_outbox` only; it is roll-forward only. No changes to Synth, ark-swapd or the Keymeld gateway and verifier.
