# Coordinator v2.16.2

The operations page can sort competitions by creation time, with newest or oldest first.
Each row shows its creation time in UTC. This helps separate recent progress from older refund and failure records.

The existing review order remains available and is the default.
Sorting applies before the 200-row display limit and works with station, competition, and review filters.
The page uses an ordinary GET form and works without JavaScript.

Deploy the coordinator package. No database migration or configuration change is required.
Synth v2.16.1 remains compatible. To roll back, restore the v2.16.1 coordinator artifact through the deployment controller.
