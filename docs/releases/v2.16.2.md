# Coordinator v2.16.2

Operations adds Newest created and Oldest created sorting, plus UTC creation timestamps.
Needs review first remains the default. Sorting precedes filtering and the 200-row display limit.

The new Keymeld page shows gateway and enclave telemetry from Grafana, plus a bounded confidential verifier capability check.
Related competitions link to milestones, retained errors, entries, and fund traces.
The Services page provides focused Oracle, worker, payment, and recovery signals with inspection guidance.
Unknown or stale data never becomes a healthy zero. Both pages use server rendering and native disclosures.

Optional monitoring can use the existing TOML settings or COORDINATOR_GRAFANA_URL, COORDINATOR_GRAFANA_DATASOURCE, and COORDINATOR_GRAFANA_TOKEN_FILE.
The token remains server-side. Keymeld 0.8.2 adds enclave observations and confidential relay counters; older gateways show those readings as unknown.

Validation includes sorting and stale/nonfinite telemetry regression tests, CI, and browser checks.
No database migration is required. This update needs only coordinator; synth v2.16.1 remains compatible.
Rollback to v2.16.1 restores the previous admin pages without changing stored competition data.
