# Dependency review for v2.0.0

The release branch updates or removes packages affected by all 14 open GitHub Dependabot alerts checked on 2026-09-19.
The comparison uses each alert's vulnerable version range and every matching package in `Cargo.lock`.
GitHub will update alert status after the changes reach the default branch and dependency analysis completes.

| Package | Previous version | Release resolution | GitHub alerts |
| --- | --- | --- | --- |
| `openssl` | 0.10.75 | 0.10.80 | #25–29, #32–34 |
| `quinn-proto` | 0.11.13 | 0.11.18 | #15, #35 |
| `rand` 0.8 | 0.8.5 | 0.8.8 | #30 |
| `protobuf` | 2.28.0 | Removed | #16 |
| `time` | 0.3.46 | 0.3.55 | #11 |
| `bytes` | 1.11.0 | 1.12.1 | #10 |

Synth exports Prometheus text metrics. Disabling Prometheus's unused default Protobuf feature removes the vulnerable decoder without changing the metrics format.
The OpenSSL bindings and vendored source are updated together; the vendored source is 3.6.3.

A fresh RustSec scan also identified issues outside those GitHub alerts.
The release updates `h2`, `rustls`, `anyhow`, and `event-listener`, and moves Nostr protocol operations to `nostr` 0.44.8.
The application does not use the Nostr SDK's relay client, so it now depends directly on the protocol crate and the browser signer.
This removes the unused relay, database, gossip, and cache dependencies.
The custom NIP-98 parser now limits encoded headers before Base64 allocation and decoded events before JSON parsing.

The dependency update preserves wallet key derivation and stored backup formats.
Compatibility tests cover fixed login and wallet examples, exact-body request authentication, and rejection of forged events.

## Raw lockfile audit limitation

`cargo audit` still reports [RUSTSEC-2023-0071](https://rustsec.org/advisories/RUSTSEC-2023-0071.html) for `rsa` 0.9.10.
SQLx 0.8.6 retains its optional MySQL driver and RSA dependency in the lockfile.
The coordinator uses SQLite, and RSA has no compiled dependency path under any workspace feature or target.
The following command produces an empty dependency tree:

```bash
cargo tree --locked --workspace --all-features --target all --invert rsa
```

Native coordinator and browser WASM dependency checks also exclude RSA.
The raw lockfile audit therefore has a nonzero exit status; this release does not claim a clean raw `cargo audit` result.
No advisory is suppressed, and no GitHub alert is dismissed.
Reassess this finding if database features change or MySQL support is added.
