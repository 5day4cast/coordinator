# Coordinator v2.10.0

This release lets players pay a ticket invoice straight from a wallet app on their phone, and makes the invoice's QR code copy the invoice when tapped ([#122](https://github.com/5day4cast/coordinator/pull/122)).

**Coordinator**

- **Wallet links.** Under the ticket invoice's QR code, the payment screen offers:
  - **Open in wallet**: a `lightning:` link, for whichever wallet the device has for that scheme.
  - **Pay with Zeus**: a `zeusln:lightning:` link.
  - **Pay with Cash App**: a `https://cash.app/launch/lightning/<invoice>` link, the format in [Voltage's wallet deep-linking guide](https://docs.voltageapi.com/wallet-deep-linking). Cash App pays only mainnet invoices, so this button shows only for them. It opens in a new tab so the payment screen keeps waiting for the payment.

  The links are set only after the wallet has checked the invoice, as the QR code is. The payment is still confirmed by the coordinator, not by the link opening.
- **Tap to copy.** Tapping the QR code copies the invoice. On an iPhone it used to hand over the QR image as base64 SVG. The code carries a "Tap to copy" badge, and the line under it confirms the copy. The long-press image menu no longer appears.
- The payment screen no longer shows the invoice as text; the QR code copies it instead.

**Required upgrade steps**

Deploy the coordinator from `v2.10.0`. There are no migrations or configuration changes. Synth has no changes in this release, but its chart and image move to `v2.10.0` with the coordinator.

**Compatibility**

Rolling back to v2.9.0 is safe. Only the payment screen's page assets changed.

**Validation**

- `cargo check` and the entry-flow unit tests pass.
- The full entry-flow browser test checks the QR code in place of the invoice text, and that a rejected invoice gets neither a QR code nor a wallet link.
- The wallet links have not yet been tried on a phone with Zeus or Cash App installed.
