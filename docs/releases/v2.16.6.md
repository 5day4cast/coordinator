# Coordinator and Synth v2.16.6

Weather discovery now displays initial eligible-station results automatically when the oracle fetch completes.
Polling stops after success or failure. Filters remain editable while loading.
Cached results and game selections stay in place during background refreshes.
A normal refresh link remains available without JavaScript.

Synth fund flows identify an unsubmitted entry by its ticket.
Expanded details label the generated entry ID as planned until submission is confirmed.
Intentional paid abandonment is a completed scenario step, while unexpected entry acceptance remains a failure.
Refund progress and payment evidence remain separate from entry submission.

Deploy Coordinator and Synth to receive both interface fixes.
This release requires no database migration or configuration change.
Both Helm charts now default to their matching v2.16.6 application images.

Validation includes full workspace Rust tests, Clippy, build and browser CI.
Targeted regressions cover cold discovery, polling termination, native refresh, retained choices, and planned versus accepted entry evidence.
These checks use fixtures and do not move customer funds.
