# Coordinator and Synth v2.23.0

## Players

Picks can no longer be edited once entered. "Edit picks" is gone from "Your picks" and the entries page, and single competitions send their entries to the oracle when their seats fill again.
An unpaid entry can be paid within 45 minutes of starting it; after that, Pay starts a new entry.
A paid entry whose page reloaded before it went in can be finished within an hour of starting it. The entry form and entries page show the time left, and after that the entry fee is refunded.

## Synth

An entry resumed after a restart whose entry id is too old to pay for starts again under a new id. A paid entry that can no longer be finished after a restart waits for its refund.

## API

- `POST /api/v1/entries/{id}/picks` is removed.
- Ticket requests refuse entry ids more than 45 minutes old, and `POST /api/v1/entries` refuses entries whose id is more than an hour old.
- `GET /api/v1/competitions/{id}/tickets/paid` adds `finish_by`, and `…/tickets/unpaid` lists only tickets that can still be paid.

## Deploying

Deploy Coordinator and Synth. This release requires no database migration or configuration change, and no changes to ark-swapd or the Keymeld gateway and verifier.
