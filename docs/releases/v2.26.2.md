# Coordinator v2.26.2

This release combines the wallet handoff fix with the merged competition and navigation updates.

Opening Satchel now keeps the player logged in to 5day4cast and completes the signed wallet handoff.
The logout listener previously handled every click in the account button container, including Open Satchel.
It could destroy the signer during the handoff and leave the wallet tab blank.
The listener now handles only the Log out button.

A browser regression test uses both production click handlers and a separate wallet origin.
It checks Open Satchel, Pay with Satchel, and explicit logout after asynchronous signing.

Upcoming competitions can be sorted by start time, total entry fee, or prize amount.
Each competition shows the player's submitted entry count and entry limit.
Sorting and counts survive list refreshes; private counts use an authenticated endpoint.

Saved picks show city names, full weather labels, and numeric thresholds or ranges.
The entry form links to payment help, including timelocks and fee caps.
The shared navigation header now reads 5day4cast on desktop and mobile.
