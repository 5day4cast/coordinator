# Coordinator and Synth v2.18.0

**Coordinator**
- Admin pages are lighter: the weather discovery station map loads after the station cards from `/admin/competition/map` (304 when unchanged; a plain link without JavaScript), every admin and operator response is gzipped, and admin assets are cacheable again. Grafana-backed service, Keymeld and operations cards refresh in the background so a first visit does not wait.
- Competitions are no longer saved when nothing changed, worker leases renew less often, and held tickets no longer wake their competition repeatedly. This cuts database write traffic and replication work.
- "Entries N of M" counts the entries that arrived.
- Lightning is treated as unsynced only after two minutes without a synced reading, for payouts and the wallet card; payouts still wait for the outcome height with two blocks of margin.
- Expected client refusals such as "Ticket not reserved" log at info.
- A queued parent becomes `pools_finished` once every pool has completed or was cancelled before funding. Migration `20261010000000_queued_pools_finished` adds a nullable column that older binaries ignore.
- A window that ends on the next local day shows the end date.
- The unused help videos are removed.
- New gauges for the Ark swap wallet: `coordinator_ark_wallet_sat{balance}`, earliest expiry, last board success and failure, and read time.

**Synth**
- Optional `[ark_refill]`: tops up the Ark swap wallet on-chain from a configured LND payer, with low and target levels, per-send and daily caps, cooldown, crash-safe sends, an "Ark wallet" dashboard card with Pause/Resume, a `/ark-refill` history page and metrics. Off by default; when enabled it replaces `rebalance.arkade`.
- Lanes start 45 s apart, picker requests share four slots and retry shed requests with backoff, and short windows use the oracle's bounded eligible-forecasts request. A start that creates no competition is recorded as a failed run and retried after 5 minutes, up to 3 times.
- Running runs resume after a restart from their last finished step; a paid entry is never paid again. Runs that cannot resume are marked interrupted with the reason.
- Health gauges include queued scenarios and ignore interruptions and failed starts.
- New counters: `synth_lane_start_retries_total`, `synth_resumed_runs_total`.

No configuration changes are required. Includes #219, #220 and #221.
