# Coordinator v2.17.2

Coordinator now requests and decodes gzip responses from Oracle. A measured
discovery response shrank from 1.46 MB to 116 KB, reducing transfer time for
previously unused weather windows and background refreshes.

This builds on the single-query discovery and default-view background refresh
from v2.17.1. Oracle v2.7.0 or later remains required. No database migration or
Synth deployment is needed.

A regression test checks compression negotiation and decoding before the
forecast response reaches the existing eligibility and ranking logic.
