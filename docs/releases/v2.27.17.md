# v2.27.17 — Synth keeps its schedule across restarts, and checkpoint writes shrink

A Synth restart no longer opens another competition for a lane whose resumed run is still taking entries.
Each startup used to resume the unfinished runs and also start the lane's next cycle at once, so a day with several restarts left several open competitions, each filling slowly. The lane's next cycle now starts when it would have without the restart.

Keymeld checkpoint writes delete only the parts the replaced version stored and the new version no longer uses.
A new checkpoint format (3), off by default, stores the part manifest as content-addressed nodes, so a write stores only the nodes that changed: in tests a state update writes 4–12 pages instead of about 280. Earlier releases cannot read format 3 rows, so enabling it limits rollback to this release or later.
`coordinator_checkpoint_written_bytes_total{kind}` reports checkpoint write volume.

No configuration or schema changes are required. The verifier enclave is unchanged; keep the deployed verifier artifact.
