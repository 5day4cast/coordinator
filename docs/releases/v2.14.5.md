# Coordinator v2.14.5

This release keeps a transforming proxy from breaking the site's navigation, lets a cache in front serve byte ranges of the help video, and makes synth charge the advertised service fee everywhere.

**Why**

With the public name behind a proxy that rewrites HTML, an analytics beacon and e-mail obfuscation scripts were injected into htmx partial responses. Both trip the site's Trusted Types policy, so every htmx swap was dropped: the address changed and the page did not. Assets were sent without a length, so the proxy's cache could not answer byte ranges and the help video could not be scrubbed. And three of synth's four competition-creation paths still charged a 10% service fee while the help page describes 3%.

**Web** ([#175](https://github.com/5day4cast/coordinator/pull/175))

- Every HTML response carries `Cache-Control: no-transform`; existing directives are kept.
- Assets under `/assets/` state their `Content-Length`.

**Synth** ([#175](https://github.com/5day4cast/coordinator/pull/175))

- All competition-creation paths use the 3% service fee.

**Required upgrade steps**

1. Deploy the coordinator and synth from `v2.14.5`. No migrations.
2. If a cache sits in front of the site, purge the two `/assets/how-it-works*.mp4` URLs once, so the stored copies carry a length.

**Compatibility**

Rolling back to v2.14.4 is safe.
