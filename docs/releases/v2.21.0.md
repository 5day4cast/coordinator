# Coordinator and Synth v2.21.0

## Players

A player holding an unpaid ticket can pay it. The entry form says the entry is unpaid and when its invoice expires, and Pay opens that ticket's invoice, with a live countdown, instead of refusing a second ticket. If the form did not know about the ticket, Pay resumes the oldest unpaid one. An expired invoice no longer blocks a new ticket. The entries page lists unpaid entries with a link to finish paying.
Resuming reuses the ticket's entry id, so the wallet derives the same entry key.

Picks can be edited until a queued competition's pools form at the start. "Your picks" and the entries page offer "Edit picks", which reopens the picks with the current choices and saves them through the same checks as a new entry. Picks in single competitions stay locked once entered.

## API

- `GET /api/v1/competitions/{id}/tickets/unpaid` lists the caller's unpaid tickets, oldest entry first.
- `POST /api/v1/entries/{id}/picks` replaces an entry's picks while they can still change.
- Ticket responses include `invoice_expires_at`.

## Deploying

Deploy Coordinator. This release requires no database migration or configuration change, and no changes to Synth, ark-swapd, or the Keymeld gateway and verifier.
