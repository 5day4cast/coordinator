# Coordinator and Synth v2.18.1

**Keymeld 0.8.2**
- Every Keymeld dependency moves from 0.7.0 to 0.8.2. The SDK treats `active_sessions` and `uptime_seconds` on the enclave listing as optional, so the coordinator and its browser client keep working when a gateway stops publishing them.
- The escrow verifier enclave is rebuilt against Keymeld 0.8.2. It seals escrow state as `escrow_state_v2` (deflated) and still reads v1 states. A verifier from before this release cannot read v2 states, so after the new verifier has sealed state it cannot be rolled back. The escrow protocol, wire framing and sealing key derivation are unchanged. Operators must pin this release's verifier enclave.

**Coordinator**
- `lease_ttl_secs` defaults to 120 seconds instead of 30. Runners renew leases a quarter as often, which cuts write transactions and replication work. A clean shutdown still releases leases at once; only takeover after a crash waits longer. Deployments that set the value explicitly are unaffected.

Includes #222 and #224.
