# Coordinator v2.1.0

This release drives each competition in its own task under a database lease, so two coordinators can run at once during a blue/green deploy.
On Mutinynet it can also fund competitions from Arkade escrows, with Keymeld signing for every player.

**Compatible components**

| Component | Version |
| --- | --- |
| Keymeld gateway | `v0.5.0` |
| Keymeld SDK and enclave crates | `feat/escrow-bip340-signing` at `4235b16`, unreleased |
| Coordinator verifier enclave and LNURL relay | `v2.1.0` |
| ark-swapd | `v2.1.0` |
| NOAA Oracle API | `v2.0.0` or later |
| dlctix | crates.io `0.1.0` |

**Changes**

- Each competition has its own runner, woken by the events it waits for: a new competition, an entry, a paid ticket, or a funded escrow. A slow step, such as an oracle retry or an Arkade batch, holds up only its own competition. See [Competition runners](../COMPETITION_RUNNERS.md).
- A competition is driven only by the coordinator holding its lease, and its saves are fenced on the lease. The payout, automatic payout, invoice, and escrow swap workers run under singleton leases. Wakes pass between coordinators through the database.
- With `ark_settings` enabled, new competitions take buy-ins in Arkade escrow VTXOs and are funded in one Arkade batch. Keymeld signs each escrow's intent proof and forfeit, and the whole contract, inside the batch. The browser checks each escrow and states where a refund goes.
- `ark-swapd` swaps a ticket's Lightning payment into its escrow from its own Ark wallet. Two instances can share its database; only the lease holder moves coins.

**Required upgrade steps**

1. Back up the coordinator databases. The migrations only add tables: `ark_funded_competitions`, `ticket_ark_escrows`, `leases`, and `competition_wakes`.
2. Optionally set `sweep_interval_secs`, `lease_ttl_secs`, `max_concurrent_steps`, and `instance_name` in `[coordinator_settings]`; the defaults suit one coordinator.
3. To run two coordinators, share one database on one host, and keep later migrations additive while both run. See [Running two coordinators](../COMPETITION_RUNNERS.md#running-two-coordinators).
4. To enable Arkade funding, set `[ark_settings]` with the Arkade server, the `ark-swapd` URL, and its token file. It requires Keymeld with automatic payouts, and the verifier enclave from this release.

**Limits**

- Arkade funding is tested on Mutinynet only. A cancelled Arkade competition does not refund its escrows yet, and escrow VTXOs expire 7 days after creation.
- With Arkade enabled, every new competition is Arkade-funded.
