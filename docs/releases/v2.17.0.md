# Coordinator and Synth v2.17.0

Synth now has persistent **Pause** and **Enable** controls for every scenario.
The dashboard shows configured schedules and recent results, including scenarios that have never run.
Pausing stops new runs. Existing runs, payments, refunds, and money tracking continue.

Every new Synth competition must use stations from Oracle's eligible list.
Scheduled lanes and manual scenario triggers select stations using forecast weather.
The Create competition form validates each explicit station choice.
Missing eligibility or forecasts stops creation before entry payments.

Coordinator's operator competition responses now include the next escrow refund opening time.
Synth can show when refunds become available instead of displaying an unknown time.

Deploy both Coordinator and Synth. Synth creates the scenario-controls table automatically.
Existing configuration remains accepted; lanes without a picker now use eligible weather selection.
See [synthetic traffic operations](../ops/synthetic-traffic.md) for control behavior and eligibility limits.

Local validation: 248 Synth tests passed, with one ignored; Synth Clippy passed with warnings denied.
Regression tests cover persistent controls, blocked creation, operator authorization, and missing eligibility or forecast evidence.
