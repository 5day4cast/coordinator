# Coordinator v2.26.1

The server now applies runtime environment settings after loading its configuration file and command-line options.
This fixes disabled feedback, visitor search, browser telemetry, and trusted proxy handling when those features are configured through environment variables.
Metrics listener and settle-only overrides also use the same startup path.

The administrative CLI still dispatches before server configuration loads.
Regression tests cover the combined settings loader and rejection of invalid environment values by the server executable.
