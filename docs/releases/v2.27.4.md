# Coordinator v2.27.4

Synth polls competition details without downloading the signed contract it does not consume.
Previously, each poll rebuilt the contract transaction graph during database decoding, including while waiting for weather observations.

`GET /api/v1/competitions/{id}?include_signed_contract=false` skips the signed contract in the database projection.
The response retains lifecycle state, contract parameters, Oracle evidence, funding transactions, outcomes, entry counts, and errors.
Existing requests receive the full response by default.
Signing, funding, and payout execution continue to load and verify the full contract.

Regression tests prove that observer reads bypass signed-contract decoding and preserve settlement evidence.
A client test checks that Synth opts out of the unused graph while retaining its funding evidence.

This release follows a successful live Mutinynet kickoff on v2.27.3: 20 players, two places, and 1,182 signing messages.
DLC signing took 13.088 seconds. The batch reached funding 24.245 seconds after selection, within its 60-second deadline.
Post-signing memory still increased, exposing this additional polling cost.
Verify the post-deployment memory trend before concluding that retention is resolved.
