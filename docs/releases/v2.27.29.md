# v2.27.29 — Retry deferred Ark wallet checks

Synth respects `Retry-After` when ark-swapd defers a wallet read with HTTP 429 or 503.
It adds jitter and stops after three attempts within four minutes, including request timeouts.
Other failures return immediately. Reads remain background work under the shared 30-request, four-minute GetVtxos budget.

Legacy Ark wallet top-ups use the payable balance, so expiring coins cannot hide a funding shortfall.
The existing boarding and settlement guards remain in place.

CI uses Ubuntu 24.04 for native builds and Playwright, with separate platform caches.
This restores browser tests that failed during installation after the runner moved to Ubuntu 26.04.
