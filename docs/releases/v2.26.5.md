# Coordinator v2.26.5

When Satchel is configured, signup guides players through creating a linked wallet and retrieves its Lightning Address automatically.
Players can still supply an existing Lightning Address.
Password signup retains the recovery key while players create the wallet in another tab.
Nostr extension signup connects the extension before opening Satchel.

On desktop, the payment dialog offers Satchel in the browser, plus invoice copying and QR scanning.
Mobile devices also show wallet app links; Cash App remains limited to mainnet invoices.
A narrow desktop window keeps the desktop behavior.

If a payment popup is blocked, Satchel opens in the current tab with the invoice ready.
Signup reports blocked popups and retains the unsaved account key for another attempt.

This release changes the coordinator UI. It requires no database migration or Satchel upgrade.
