# Coordinator and Synth v2.20.0

## Contracts

The coordinator moves to dlctix 0.2.2. New competitions build contracts whose split transactions are bound to their outcome, and every outcome, expiry and split transaction carries a 240-sat pay-to-anchor output, so a stuck transaction can be fee-bumped by anyone (CPFP), including a player recovering on their own.
Each competition stores the contract options it was created with. Competitions created before this release keep building, verifying and recovering their contracts exactly as before.
Players' wallets and the verifier enclave check the options: an anchor must be between 240 and 1,000 sats, and splits must be bound whenever two outcomes pay the same winners.
`coordinator-recover` finds a contract's anchor outputs.

## Players

The entry fee's network share now includes the outcome transaction's anchor: 13 vB at the priced rate plus the anchor value shared across the priced pool. At a 1.264 sat/vB contract rate it rises from 179 to 232 sats, and entries pause from about 3.74 sat/vB instead of 4.18. Payouts are unchanged.
The entry form states the tie rule under the prize split: ties go to the earliest entry.

## Deploying

Release and deploy the Keymeld gateway and enclaves (Keymeld 0.9.1), the coordinator's verifier enclave, Coordinator, Synth and ark-swapd together, before any new competition reaches signing; an older verifier does not know the new contract options.
This release requires no database migration or configuration change.
