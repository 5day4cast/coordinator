# Coordinator v2.11.0

This release acts on the first round of player feedback from a test session ([#124](https://github.com/5day4cast/coordinator/pull/124)). Every change is in the pages; the API, contracts and scoring are untouched.

**Coordinator**

- **Competitions list.** Upcoming competitions are listed above live ones. A queued competition that has been split into pools shows its pools' phase in the list instead of "Split into pools" (its row already stands in for them), and a single pool reads "1 pool".
- **Copy.** The intro and the entry form say to call each reading **Over**, **Par** or **Under**, in place of "over the forecast, on it (par) or under it". The entry form says that any reading may be left at No pick and scores 0.
- **Par bands off the forecast.** Under lines rules a station's Par band is fitted on how its forecasts have missed, so it can sit entirely to one side of the forecast (ATL: forecast 84°F, Par 80.4–83.0°F), which read like a bug. The forecast stays the headline number, and a note beside the band says which way the station's forecasts have leaned: *forecasts here have run ~2°F hot lately*. The same note appears in the picks dialog.
- **Picks dialog.** Each badge explains itself on hover, and while the window is open a legend says what *on track*, *off track*, *locked in* and *out* mean. Live rows show the points each pick earns as if the window ended now, under its badge.
- **Leaderboard.** The footnote says that when a tie spans the last paid place, the earlier entry is paid. Once the oracle's result is in, the paid rows are marked.
- **Own picks before the start.** A player can see their own picks before the window opens. The public picks dialog asks `/entries/{id}/detail/mine` on load; the request is signed when the player is logged in, and the server answers with the entry's picks only to its owner (`Cache-Control: private, no-store`). Anyone else gets the same withheld message as before, and the dialog's minute-by-minute refresh stays unsigned.

**Required upgrade steps**

Deploy the coordinator from `v2.11.0`. There are no migrations or configuration changes. Synth has no changes in this release, but its chart and image move to `v2.11.0` with the coordinator.

**Compatibility**

Rolling back to v2.10.0 is safe. Only page assets and one new page route (`/entries/{id}/detail/mine`) changed.

**Validation**

- `cargo clippy` is clean; the template and leaderboard unit tests pass (98), with new tests for the lean text, the owner's and the withheld picks dialogs, per-pick live points, the paid-row marker on a tie, and the list badge of a split queue.
- The htmx auth unit tests (52) cover the new signed URL and that the public picks dialog stays unsigned.
- Seeing one's own picks before the start has not yet been tried in a browser against a live coordinator.
