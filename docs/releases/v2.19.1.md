# Coordinator and Synth v2.19.1

## Competitions

New competitions pay one winning place for now; two-place pools stay supported in the code and can be re-enabled with a setting once a pending contract change lands.
The setting is `[coordinator_settings] max_winning_places` (1 or 2, default 1). Every creation path checks it before any oracle, ticket or database effect: the admin form, the JSON API and the admin CLI. Competitions that already exist keep their places.
The admin form's "Winning places" defaults to 1, with its maximum taken from the setting.
Synth's queued scenarios default to one place; the 20-entry cap is unchanged.
A one-pool competition paying one place shows "Winner takes all".

Upgrade from v2.19.0 directly; deploy this release rather than v2.19.0. No configuration change is required.
