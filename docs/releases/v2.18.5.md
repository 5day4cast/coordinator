# Coordinator and Synth v2.18.5

Coordinator prices on-chain transactions from its configured local electrs server.
The 144-block historical estimate supplies the baseline, bounded by the relay minimum and LND's wallet minimum.
Current mempool demand raises that baseline when more transactions compete for the requested confirmation window.
The existing contract margin still applies.

This corrects excessive fees when short-target estimates have too few recent samples at lower rates.
For the observed Mutinynet pool, a 1.029 sat/vB baseline produces a 1.280 sat/vB contract rate and permits the three-player kickoff.
Confirmation targets remain estimates; the 144-block baseline alone does not promise next-block confirmation.

The configured Electrum server must support `blockchain.estimatefee`, `blockchain.relayfee`, and `mempool.get_fee_histogram`.
Missing or invalid responses pause pricing until valid estimates return.
The existing local Mutinynet electrs instance supports all three methods.

Deploy Coordinator to apply this change.
This release requires no database migration or changes to Synth, ark-swapd, or the Keymeld gateway and verifier.
