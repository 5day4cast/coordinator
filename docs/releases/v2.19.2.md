# Coordinator and Synth v2.19.2

Lightning Addresses are no longer followed directly by punctuation, so copying one does not pick up a trailing period.
This covers the entry form's payout line, the default address on the payouts page, and the messages shown when an address cannot be checked.

Deploy Coordinator to apply this change.
This release requires no database migration or configuration change, and no changes to Synth, ark-swapd, or the Keymeld gateway and verifier.
