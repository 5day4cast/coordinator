# Coordinator v2.5.0

This release adds an optional Prometheus metrics listener and an operator command line, and makes log-in faster: the browser module is smaller, and password stretching runs off the page's thread.

**Compatible components**

| Component | Version |
| --- | --- |
| Keymeld gateway | `v0.5.0` or later |
| Keymeld SDK, core and enclave crates | `v0.6.0` |
| Coordinator verifier enclave and LNURL relay | `v2.4.0` or later |
| ark-swapd | `v2.5.0` |
| synth | `v2.5.0` |
| NOAA Oracle API | `v2.3.0` or later |
| dlctix | crates.io `0.1.0` |

**Changes**

- **Metrics listener (#90).** Set `[metrics_settings] listen_addr` (or `COORDINATOR_METRICS_LISTEN_ADDR`) and the coordinator serves `GET /metrics` on its own socket.
  - It is off by default, has no authentication, and the public and admin listeners never expose it.
  - Gauges: competitions by state, entries, tickets, payouts, and payout jobs (open, failed, retrying, oldest open age).
  - Counters: payout attempts, and competition step failures.
  - Also reported: background thread health and build info.
- **`coordinator admin competitions list/show/create/cancel` (#92).** Talks to the operator listener with the bearer token read from a file. The operator listener gains `GET /api/v1/admin/competitions[/{id}]` and `DELETE /api/v1/admin/competitions/{id}`.
- **synth (#92).** `synth run <scenario> [--wait]` and `synth runs list/show`. `POST /api/run` returns the new run's `run_id`, and `GET /api/runs/{id}` returns a run and its steps.
- **Log-in (#91):**
  - The browser module is built with LTO, one codegen unit, panic=abort and `wasm-opt -Oz`.
  - The key-derivation crates are fully optimised.
  - The release ships brotli and gzip copies, and the server prefers brotli.
  - Password stretching (scrypt) runs in a worker. The Nostr key and the vault key stay in the page's WASM.
  - The CSP allows a second Trusted Types policy, `login-worker`, which admits only the worker's URL.

**Required upgrade steps**

1. Back up the coordinator database. This release adds no migration.
2. Deploy ark-swapd and synth from this release together with the coordinator. No Keymeld or enclave change is needed.
3. To collect metrics, set `[metrics_settings] listen_addr` to a loopback or private address, and scrape `/metrics` there.

**Limits**

- The metrics listener has no authentication; don't bind it to a public address.
- synth's API has no authentication of its own; reach it only over a private network.
