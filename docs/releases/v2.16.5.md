# Coordinator v2.16.5

The admin Operations page adds Finished and Paid out views for competition support.
Both views retain the newest-created-first ordering and links to fund-flow evidence.

Finished includes signed results, expiry settlements, and completed contracts.
Paid out requires successful recorded Lightning payments for every recipient owed money under the settled contract outcome.
Contract cleanup and customer payment remain separate states.

This release also includes the current help-page explanations from v2.16.4.
No database migration is required. Deployed synth v2.16.1 remains compatible.
