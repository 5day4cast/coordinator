# Coordinator v2.15.2

This release clarifies competition entry and prevents duplicate synthetic competitions at startup.

## Coordinator

- Show Prizes, a local weekday and start time, and a separate observation duration.
- Show one total Entry fee. Check the required pick count before payment.
- Require the advertised number of picks and reject duplicate city rows. Existing submitted entries remain valid.
- Derive the pick count for new admin-created competitions from every selected city and scored category.
- Identify each city's airport station in a tooltip. Distinguish NOAA forecasts from the historical model's pick ranges.
- Update help with selection, scoring, deadlines, and payout explanations. Replace stale videos with native examples.
- Clarify admin fee fields and the movement of funds from payment through settlement.
- Synchronize the escrow-subscription test's related reads with settlement commits.

## Synth

- Share scheduled lane starts with the keep-open check. Ignore duplicate startup wake-ups during the opening grace period.
- Cache eligible stations separately for each history length and observation window. Validate the supported history range.

## Upgrade

Deploy coordinator and synth together. No database migrations are included.

Existing capped competitions retain their advertised count; new submissions must fill that count exactly.
API clients must submit the required count without repeating a city.

Observation retention is configured separately in infrastructure. The new 32-day retention cannot restore files already removed.
Keep the configured three-day eligibility window until sufficient continuous history is available.
