# Coordinator and Synth v2.25.0

## Satchel test wallet

- New optional `[ui_settings] satchel_url`, the origin of a [Satchel](https://github.com/tee8z/satchel) test wallet. The coordinator refuses it on mainnet.
- When it is set, players get **Pay with Satchel** beside **Pay with Zeus** in the payment dialog, **Open Satchel** in the account menu, and their Satchel Lightning Address on the Payouts page.
- When the player's key is in the page, these sign them in to Satchel with a signed Nostr handoff. A player without a wallet there is offered one.
- The pages' Content-Security-Policy adds the origin to `form-action` and `connect-src` only when it is set.
- Helm: `config.ui.satchelUrl`.

## Sign-up proof of work

- New optional `[pow]` section, off by default. When enabled, every new account carries a small proof of work: username and password sign-ups and Nostr-extension sign-ups alike.
- The sign-up dialog solves it in the background, about a second on a phone at 18 bits, usually before the player has finished typing. Signing in never needs one.
- Difficulty is global, never per client address, so a crowd behind one address pays the same as anyone. It rises one bit for every `step_signups` accounts created in the last hour, up to `max_bits`.
- New endpoint: `POST /api/v1/users/pow`. A rejected proof answers 400 with `"code": "pow_rejected"`, and the dialog retries once with a fresh challenge.
- New metrics: `coordinator_signup_pow_checks_total{result}` and `coordinator_signup_pow_difficulty_bits`.

## Upgrading

Both settings are optional, and existing configurations load unchanged.
