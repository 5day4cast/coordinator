# Coordinator v2.27.0

Visitors can join the mainnet launch email list from the Mainnet signup link beside Feedback.
The form opens in a dialog and also works without JavaScript.
It validates email addresses, prevents duplicates, and applies proof-of-work and request limits.

Operators can view collected addresses and download a CSV from Mainnet signups in the admin navigation.
The form is enabled by default.
Set `[mainnet_signup].enabled = false` to close the form while retaining access to the list.

The competition list shows compact capacity counts such as `7/20` for seven seats remaining out of twenty.
Tooltips and screen-reader text retain the full explanation.
Held seats continue to count toward capacity.

Startup adds the `mainnet_signups` table to the users database.
The migration is additive and preserves existing accounts and feedback.
Existing users-database backups include the signup list.
