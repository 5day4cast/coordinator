# Coordinator v2.16.1

The admin and synth fund-flow screens show the refund branch before a refund swap exists.

- Follow each escrow through its Arkade return and Lightning refund.
- See the escrow opening time, cancellation or queue trigger, current swap creation, and latest recorded state update.
- Distinguish a recorded Arkade transfer from a recorded Lightning payment. Write-offs do not count as payment.
- See pending refunds in compact pool rows. Escrows already moved into a funded pool do not show a new refund promise.
- Expand evidence with native HTML in light or dark mode.

Opening times come from the escrow script. Cleanup also waits for confirmed chain time and available services.
The opening time is not a promised payment time. The latest state update is not an exact Lightning settlement timestamp.

Deploy coordinator and synth together. No database migration or configuration change is required.
The ticket-refund response adds optional `created_at` metadata. Older synth trails remain readable; missing times appear as unrecorded.

To roll back, restore the v2.16.0 coordinator and synth artifacts through the deployment controller.
