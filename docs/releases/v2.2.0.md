# Coordinator v2.2.0

This release refunds the Arkade escrows of a competition that never kicks off, with each player's own consent, and ships `synth`, which runs synthetic competitions against a coordinator and shows how each one fares.

**Compatible components**

| Component | Version |
| --- | --- |
| Keymeld gateway | `v0.5.0` |
| Keymeld SDK and enclave crates | `feat/escrow-unbound-refunds` at `98f3420`, unreleased |
| Coordinator verifier enclave and LNURL relay | `v2.2.0` |
| ark-swapd | `v2.2.0` |
| synth | `v2.2.0` |
| NOAA Oracle API | `v2.0.0` or later |
| dlctix | crates.io `0.1.0` |

**Changes**

- A competition that never kicks off refunds its entries' escrows. Each player authorizes the refund with the consent they gave when entering, Keymeld signs it, and `ark-swapd` swaps it to the player's Lightning address. A refund interrupted while Arkade holds it finishes on the next pass.
- The verifier enclave reads the refund terms players consent to.
- `ark-swapd` boards coins once they confirm at its boarding address, so on-chain top-ups reach its Ark wallet without an operator.
- `synth` is packaged with the Linux release. It runs competitions on a schedule, pays from a configured node and keeps that node and `ark-swapd` funded, traces each run's money, and streams runs live to its dashboard.
- Release dry runs can skip the container images and reuse earlier builds.

**Required upgrade steps**

1. Back up the coordinator databases. Migration `0003_refunds` adds the `refunds` and `ticket_ark_refunds` tables. A 2.1.0 coordinator refuses to start against a database with a migration it does not know, so after the upgrade, returning to 2.1.0 needs the backup.
2. Deploy the verifier enclave and `ark-swapd` from this release together with the coordinator. Competitions created under 2.2.0 carry refund terms that earlier enclaves do not read.
3. Optionally set `max_refund_fee_sats` in `[ark_settings]` to bound the fee a refund may pay.

**Limits**

- Arkade funding and refunds are tested on Mutinynet only. Escrow VTXOs expire 7 days after creation.
