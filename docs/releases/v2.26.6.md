# Coordinator v2.26.6

The custom enclave reuses public signing requirements for the same funded contract.
Each participant's authorization, signing scope, roster and adaptor points remain checked.
The cache holds at most four contracts and eight MiB of retained data.
Changed funding outpoints or contract parameters require a new derivation.

Coordinator, its SDK and its custom enclave use Keymeld 0.10.1.
Completed enclave commands retain replay metadata instead of their request payloads.
Deploy the rebuilt custom enclave to receive both signing changes.
The gateway release alone does not replace that enclave.

Signing logs report setup, round preparation, participant permits and MuSig durations.
An optional benchmark exercises 20 players, two places and three enclaves through
real encrypted transport, with a scripted Arkade server and verified forfeits.

Synth requires current coverage evidence from Oracle 2.9.1 before selecting stations.
Stations with no missed-report gap rank ahead of stations that need that allowance.
Saved selection reasons include recent coverage and the largest report gap.
Deploy Oracle 2.9.1 before this Synth release.

Synth also checks visitor entry forms when its competition scheduler is disabled.
The new visitor-check timestamp supports the staging monitoring alerts.

These changes do not repair missing historical weather observations or guarantee
future coverage. Settlement continues to enforce its existing data requirements.
